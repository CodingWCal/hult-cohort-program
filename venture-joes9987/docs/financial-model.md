# Financial model — EudaLearn (illustrative)

Assumptions are labeled. Not audited. Units USD.

## Core assumptions

| Assumption | Value | Rationale |
|------------|-------|-----------|
| BYOB engineer share | 70% | Ludwitt Creator docs |
| Avg credit spend / MAU / month | $2.00 | Coach tips light usage |
| Organic CAC (Y1) | $2 | Founder distribution |
| B2B seat price / learner / cohort | $25 | Pilot pack |
| Gross margin (software) | 85% | Vercel + Supabase + Ludwitt proxy |

## Year 1–3 sketch

### Year 1

| Month band | MAU | BYOB net rev | B2B rev | Total |
|------------|-----|--------------|--------|-------|
| M1–M3 | 50 → 300 | $0.2k → $1.2k | $0 | ~$2k |
| M4–M6 | 500 → 1,200 | $2k → $5k | $5k (2 pilots) | ~$15k |
| M7–M12 | 1,500 → 3,000 | $6k → $12k | $20k | ~$40–80k FY |

### Year 2

- MAU 8k–15k  
- BYOB ~$120–200k  
- B2B ~$150–200k  
- **Total ~$250–400k**

### Year 3

- MAU 25k–40k  
- Mix shifts to B2B seats + credit top-ups  
- **Total ~$800k–1.2M**

## Cost stack (Y1)

| Item | Annual |
|------|--------|
| Founder draw (minimal) | $0–30k |
| Hosting / DB | $0.5–2k |
| Contractor content | $5–15k |
| Tools | $1k |
| **Total** | **~$10–50k** depending on draw |

## Sensitivity

- If avg spend/MAU = $0.50 → lean on B2B earlier.  
- If marketplace distribution fails → suite + direct cohort sales.  
- If Ludwitt take-rate changes → renegotiate or multi-home credits.
