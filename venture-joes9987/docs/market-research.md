# Market research — EudaLearn

**Founder:** @joes9987 · Hult Summer Pilot 2026 · Venture week  
**Product:** Short builder-skills practice modules with Ludwitt identity + credit-backed AI coach.

## Problem

Builders using AI coding agents ship faster but lack a lightweight, instrumented way to practice the *meta-skills* that make agents useful: writing shippable briefs, trusting launch tokens, firing learning events, and thinking in product suites. Existing LMS tools are heavy; Twitter tips are unmeasured; internal cohort tools do not bill through a shared credit wallet students already have (Ludwitt).

## ICP (ideal customer profile)

1. **Primary:** Early-career builders / bootcamp & cohort graduates who already have a Ludwitt (or similar) account and need proof-of-practice, not another 40-hour course.
2. **Secondary (B2B):** Cohort operators and placement programs that need ≥N external practice sessions attributed per participant app.
3. **Buyer of credits:** The learner (BYOB) or the program (bulk credits later).

## Wedge

Start as **8–10 minute modules** on Ludwitt marketplace with counted events — not a full LMS. Expand to B2B cohort packs once ≥25–100 weekly active practicers exist.

## Discovery interviews (n=5)

Notes anonymized. Roles only.

### Interview 1 — Indie hacker (shipped 2 AI side projects)

- Pain: “I know I should write better prompts/briefs but I never practice deliberately.”
- Would try an 8-minute module if sign-in is one click.
- Skeptical of long courses; wants immediate feedback (coach tip resonated).
- Willing to spend small credit amounts if value is clear in-session.

### Interview 2 — Bootcamp grad (job search)

- Needs artifacts and proof for portfolio; short quizzes feel legitimate if scored.
- Prefers marketplace / known identity over yet another password.
- Distribution tip: LinkedIn posts from peers convert better than cold Discord.

### Interview 3 — Startup eng (Series A)

- Team already uses AI pair tools; meta-skills training is ad hoc in Notion.
- Would buy **team packs** if managers see completion metrics.
- Competes with internal lunch-and-learns, not Coursera.

### Interview 4 — Cohort operator / facilitator

- Needs external user counts that survive audit (anti-gaming).
- Listing URL > raw Vercel URL for attribution narratives.
- Care about privacy page + clear data story for participants.

### Interview 5 — Angel / advisor (edtech adjacent)

- Likes BYOB rev-share (70% engineer) as aligned incentives.
- Asks for retention beyond one module and a path to B2B.
- Deck must show live product + real users, not only vision.

## TAM / SAM / SOM (order-of-magnitude)

Assumptions labeled; not a diligence-grade model.

| Layer | Definition | Estimate |
|-------|------------|----------|
| **TAM** | Global spend on developer upskilling + AI tooling education (online) | ~$50B+/yr category umbrella (broad) |
| **SAM** | English-speaking builders in AI-assisted coding cohorts / bootcamps / indie markets who would use short practice apps | ~5M people × $20–50/yr practice spend ≈ **$100–250M** |
| **SOM (Y1–Y2)** | Ludwitt marketplace + Hult-like pilots + warm LinkedIn distribution | 2k–10k practicers × $12–36/yr credits ≈ **$25k–350k** revenue to app via 70% share |

SOM is deliberately small: win marketplace density first.

## Competitors (≥5)

| Competitor | Type | Gap vs EudaLearn |
|------------|------|------------------|
| Coursera / Udemy AI courses | Long-form LMS | Slow; not Ludwitt-attributed; weak practice loop |
| PromptBase / prompt marketplaces | Asset marketplaces | Sell prompts, not practice + events |
| Internal Notion playbooks | Informal | No metrics, no credits, no coach |
| Duolingo-for-X clones | Habit apps | Rarely ship builder-ops skills; no suite GTM |
| Cohort-native tools (own PM/chat) | Horizontal suite pieces | Don’t teach learning instrumentation |
| Generic ChatGPT | Freeform | No structured modules, no audited sessions |

## Insights → product

1. Keep modules under 10 minutes.
2. Ludwitt OAuth as default (approved listing).
3. Show “session recorded” without dumping internal event names.
4. Suite deep links for distribution; marketplace URL for attribution.
5. Coach tips are a differentiator if credits work; degrade gracefully if not.
